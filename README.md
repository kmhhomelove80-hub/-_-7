# 키움 A/B 순환매 · Windows 데스크톱

A는 자금을 보관하는 배당 ETF, B는 상대적으로 변동이 큰 종목으로 설정합니다. **B의 직전 실제 체결가**를 기준으로 반대 방향 매매를 기다리는 프로그램입니다.

[Windows 실행파일 다운로드 — GitHub Releases](https://github.com/kmhhomelove80-hub/-_-7/releases)

`KiwoomTwoStockTrader.exe` 또는 `KiwoomTwoStockTrader-Windows-x64.zip`을 다운로드하세요. Windows 10/11 x64용이며 Python 설치가 필요 없습니다. 코드서명은 포함하지 않습니다.

## 새 매매 규칙

| 대기 상태 | 신호(기본값) | 매매 |
|---|---|---|
| B 매수 대기 | 직전 B 매도가에서 5% 하락 | A 보유수량의 10% 매도 → 그 금액으로 B 매수 |
| B 매도 대기 | 직전 B 매수가에서 5% 상승 | B 보유수량의 5% 매도 → 그 금액으로 A 매수 |

예: B **10,500원 매도 → 9,975원 매수 → 10,473.75원 이상에서 매도 신호**. 실제 주문은 유효한 현재가 지정가를 사용하며 신호가격과 실제 체결가격은 다를 수 있습니다. 부분체결 가격은 수량가중 평균으로 합산합니다.

- A 가격 자체로 매매 신호를 만들지 않습니다.
- B 매도 후에는 매수만, B 매수 후에는 매도만 기다립니다. 같은 방향으로 연속 물타기/매도하지 않습니다.
- 모든 등락·수량 비율을 UI에서 변경할 수 있습니다.
- 첫 기준은 기본적으로 시작 시 B 평균 매입가, 첫 방향은 BOTH(양방향)입니다. 직접 첫 기준가를 입력하거나 BUY/SELL 방향을 선택할 수 있습니다.
- 이후 기준과 방향은 계좌·A·B별로 저장됩니다. 재시작해도 유지하며 첫 설정을 다시 적용하려면 중지 후 **B 기준 초기화**를 누릅니다.
- A 최소 잔고는 없습니다. 실제 매도가능수량과 비용/정수 주식 제약은 적용합니다.
- A+B 합산 매입원금 한도 **100만원~10억원**, 하루 최대 사이클 수를 설정합니다.

## 계좌 잔고

저장 인증정보가 있으면 조회 전용으로 자동 연결합니다. 계좌 전체 보유종목과 예수금·주문가능현금·평가손익을 약 5초마다 재조회합니다. 마지막 갱신 시각과 지연/오류를 표시하며, 자동매매 중지와 조회 연결 해제는 별도입니다. WebSocket 틱 스트리밍 방식은 아닙니다.

## 휴대폰 알림

**휴대폰 알림 설정**에서 텔레그램을 기본 채널로 설정하고, 이메일도 선택적으로 사용할 수 있습니다. 둘 다 켜면 두 채널로 발송합니다.

1. 텔레그램에서 `@BotFather`의 `/newbot`으로 봇 생성 후 토큰을 복사합니다.
2. 생성한 봇과 대화를 열고 `/start`를 보냅니다.
3. 프로그램에서 토큰 입력 → **Chat ID 찾기** → 저장 → **테스트 알림 보내기**.
4. 휴대폰에서 텔레그램 알림을 허용합니다.

이메일은 SMTP 서버·보안 방식·인증정보·수신 주소를 입력하고 테스트합니다. 모든 알림 인증정보는 Windows 자격 증명 저장소에 보관합니다. 알림 실패가 주문 재실행으로 이어지지 않도록 별도 대기열에서 처리합니다. 토큰이나 SMTP 오류 응답 원문을 로그에 출력하지 않습니다.

## 검증과 실행

자동 테스트와 Windows 원본/EXE UI 시작 테스트를 통과한 빌드만 Release에 게시합니다. **실계좌 인증·주문·체결 및 사용자의 텔레그램/SMTP 수신은 아직 종단간 검증하지 않았습니다.** 사용자 PC에서 조회 및 알림 테스트를 먼저 확인하세요. 프로그램 실행만으로 자동매매를 시작하지 않습니다.

[사용설명서](사용설명서.md)에 한도 의미, 첫 기준 설정, 오류 복구, 알림 설정을 자세히 설명했습니다. **중지 버튼은 접수된 주문을 취소하지 않습니다.**

소스 실행: Python 3.12 권장, `설치.bat` → `실행.bat`. 소스 테스트 및 빌드:

```powershell
python -m unittest discover -s tests -v
python -m pip install -r requirements-build.txt
./scripts/build_windows.ps1
```

인증정보, 실계좌 DB, 설정 파일을 저장소에 업로드하지 마세요.
