# 키움 A/B 수익률 갭 순환매 — PC 로컬 웹

A·B 각각의 **평균 매입가 대비 현재 수익률 차이**가 설정 갭에 도달하면 수익률이 높은 종목을 팔아 낮은 종목을 사는 Windows 실전계좌용 프로그램입니다. 기존 B 단독 신호 전략은 제거했습니다.

- 양방향 시장가 매도 → 실제 매도대금 내 시장가 매수, 체결·잔고·평균가 확인.
- 당일 최초 보유수량 × 비율을 반올림한 고정 주수 또는 현재 보유수량 비율 선택.
- 거래 후 갭이 기준 미만으로 줄어든 것을 확인한 뒤 재도달해야 재거래. 재진입 상태·당일 고정수량은 재실행 후에도 유지.
- 한 번 승인하면 기간 제한 없이 매 거래일 자동 실행·점검·매매·종료. 사용자 중단 또는 확인이 필요한 오류 전까지 운영.
- 특별 이슈 중심 텔레그램/이메일 알림: 사유·원인·조치·해결 방법·재개 조건. 안전한 주문 전 조회 오류는 자동 재점검.
- 시장가도 미체결/부분체결이 가능합니다. 매수 수량은 상한가·비용 예비율로 보수적으로 산정하며 자동 주문 재전송은 없습니다.

[최신 다운로드 목록](https://github.com/kmhhomelove80-hub/-_-7/releases) · [사용설명서](웹버전_사용설명서.md)

기존 앱 종료 후 `KiwoomWebTrader.exe`를 고정 폴더에 두고 실행합니다. 계좌·새 전략·알림을 확인한 뒤 예약 화면에서 실전 자동 운영에 한 번 동의하세요. 전략 변경으로 기존 예약 동의는 만료됩니다. PC 전원과 Windows 로그인은 필요합니다.

소스 실행: Windows Python 3.12에서 `pip install -r requirements.txt`, `python web_app.py`. 조회 전용 화면: `python web_app.py --demo`. 빌드: `scripts/build_windows.ps1`. 합성 계좌 테스트: `python -m unittest discover -s tests -v`.

기존 인증정보·설정·거래 기록은 같은 로컬 경로를 사용합니다. 기존 B 기준가·방향은 새 로직에서 읽지 않습니다. `app.py`는 웹 앱 실행기로 교체하여 이전 전략을 실행할 수 없게 했습니다.

실제 실전 주문·체결, 사용자 PC 장기 연속 운영·깨우기, 휴대폰 수신은 개발 환경에서 검증하지 않았습니다.
